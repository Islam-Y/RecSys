# T-Lab 2026 — RecSys

Рабочая папка для подготовки к отбору на программу T-Lab 2026 по рекомендательным системам.

## Документы

- [Условия заданий](Задания.md) — описание первого задания и место для второго.
- [Черновик решения](Решение.md) — постановка задачи, теория, план экспериментов и открытые вопросы.

## Статус

- Задание 1: условия получены, изучаем постановку.
- Задание 2: условия пока не добавлены.
- Стек первой версии зафиксирован: Python, DuckDB + Parquet, CatBoost, scikit-learn и локальный MLflow.
- Решение: концепция и план зафиксированы; датасет, реализация и экспериментальные результаты ещё не добавлены.
- Итоговый PDF: подготовим после того, как стабилизируем Markdown и получим результаты.

## Этапы работы

1. Добавить оба условия и уточнить семантику данных.
2. Изучить близкие решения по feature stores, автоматической генерации признаков и retrieval/ranking.
3. Выбрать воспроизводимый временной протокол и метрики.
4. Собрать и оценить базовую модель с ручными признаками.
5. Проверить идею автоматизированной генерации временных признаков.
6. Описать эксперименты и ограничения, затем собрать итоговый отчёт.
