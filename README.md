# T-Lab 2026 — RecSys

Подготовка к отбору на программу T-Lab 2026 по рекомендательным системам. Материалы разложены по заданиям, чтобы условия, решения и будущие эксперименты не смешивались.

## Проекты

- [Задание 1](assignment-1/README.md) — исследование признаков для рекомендательной системы, временные агрегаты и бустинговый baseline. Сейчас ведём работу здесь.
- [Задание 2](assignment-2/README.md) — отдельная папка подготовлена; добавим условие и материалы, когда получим задание.

## Общие принципы

- Сначала фиксируем условия и план в Markdown.
- Эксперименты должны быть воспроизводимыми и не использовать информацию из будущего.
- Итоговый отчёт в PDF подготовим после завершения экспериментов.
