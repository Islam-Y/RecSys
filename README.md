# T-Lab 2026 — RecSys

Отдельный проект для первого задания отбора T-Lab 2026 по рекомендательным системам: признаки, временные агрегаты, автоматизация feature engineering и бустинговый baseline.

## Материалы

- [Условие задания](Задание.md)
- [Черновик решения и план исследования](Решение.md)

Статус: постановка и план зафиксированы; датасет, реализация и результаты экспериментов ещё не добавлены. Стек MVP: Python, DuckDB + Parquet, CatBoost, scikit-learn и локальный MLflow.

Второе, отдельное задание посвящено последовательным рекомендациям и RL: [репозиторий RecSys-RL](https://github.com/Islam-Y/RecSys-RL).

Страница отбора: [T-Lab 2026. RecSys](https://edu.tbank.ru/selection/01a10b8d-f3da-73a2-950e-5395aeccdb3d).
