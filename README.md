# T-Lab 2026 — RecSys

Первое задание отбора: временные признаки и проверка автоматизированного отбора признаков для CatBoost. Эксперимент завершён; положительный результат по компактности модели получен, общий критерий качества и стоимости не выполнен.

## Результат

На проверке из 7 025 запросов автоматические 8 признаков получили NDCG@3 0.43434 против 0.44435 у ручных 12. Расчёт был на 14.2% медленнее, пиковая память выше на 21.9%; числовая матрица и файл модели оказались меньше. Это offline-оценка на сэмплированных неизвестных, не CTR и не онлайн-эффект.
